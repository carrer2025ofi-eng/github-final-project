# Simple Interest Calculator

This project is a Bash script that calculates simple interest based on user input.

## Project Description

The script asks the user for three values:

- Principal amount
- Annual rate of interest
- Time period in years

Then it calculates simple interest using the formula:

```text
Simple Interest = (Principal x Rate x Time) / 100
```

## File Included

- `simple-interest.sh`: Bash script for calculating simple interest.

## How To Run

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
