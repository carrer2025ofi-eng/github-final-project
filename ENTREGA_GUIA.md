# Guia De Entrega Del Proyecto Final

## Parte 1: GitHub Interface

Debes subir estos archivos a un repositorio publico de GitHub:

- `README.md`
- `LICENSE`
- `CODE_OF_CONDUCT.md`
- `CONTRIBUTING.md`
- `simple-interest.sh`

Cuando esten subidos, debes copiar las URLs publicas de cada archivo segun pide la tarea.

## Parte 2: Git CLI

Estas tareas dependen del repositorio bifurcado del curso:

`ibm-developer-skills-network/mcino-introduction-to-git-and-github`

Necesitaremos tu fork para generar estas evidencias:

- `forked-repo`
- `merge_branches`
- `bug-fix-revert`
- `github-branches`

## Comandos utiles

```bash
git status
git add .
git commit -m "Add required project files"
git branch
git log --oneline
git remote -v
git push -u origin main
```

## Siguiente paso

Crear un repositorio publico en GitHub llamado, por ejemplo:

`github-final-project`
